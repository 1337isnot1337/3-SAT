# Polynomial construction of initial sparse checks

Status: author-checked scoped argument pending independent review. Base `630041c9da3a26edb8c8f59d5f8a4132a188c8bd`. Coordination: [issue #70](https://github.com/1337isnot1337/3-SAT/issues/70). Contributor: Cinna Davis with substantial OpenAI Codex assistance.

[PROOF.md](PROOF.md) gives deterministic polynomial-time constructions of the Walsh shift family and the local check code in the accepted theorem's initial Tanner sparse-check matrix. The original version preserves the source parameters and output contract; [RETUNED.md](RETUNED.md) also gives a stronger distance threshold and narrower rows by changing those parameters. Omitting zero rows gives the stronger [row-count bound](ROW-COUNT.md): fewer than n/25 initial checks in general and O(n log log n / log n) for source polylogarithmic density. The source uses exhaustive search costing exp(polylog n); the new construction is polynomial in n, m, and the numeric value of B. This is a preprocessing result, not a new SAT exponent or alpha. [REDUNDANCY.md](REDUNDANCY.md) proves a complementary coding bound: stronger distance requires additional independent checks, and the original row-count asymptotic cannot be transferred unchanged to the retuned parameters. PR #51 separately reduces greedy candidate enumeration; [COMPOSITION.md](COMPOSITION.md) charges both improvements, all oracle calls, and the unchanged contraction cost.

Run `python3 -I -B research/polynomial-sparse-checks/verify.py`, `python3 -I -B research/polynomial-sparse-checks/verify_source.py`, `python3 -I -B research/polynomial-sparse-checks/verify_retuned.py`, `python3 -I -B research/polynomial-sparse-checks/verify_redundancy.py`, and `make verify`. The bounded reference [tanner.py](tanner.py) implements the source parameters with explicit resource caps. Its source-parameter replay uses n=m=2048, B=1 and q=1; a retuned-parameter replay uses n=m=16384, B=1 and q=1. The nontrivial q>1 shift construction is not replayed at source size. The checker covers small independently enumerable potential and local-code cases and exhausts a scaled 16-edge Cayley-Tanner fixture before and after shortening. The fixture does not instantiate the source parameters; this is not a q>1 source-parameter replay or an independent proof review.
