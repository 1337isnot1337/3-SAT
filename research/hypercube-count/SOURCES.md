# External source and attribution

W. Fish, J. D. Key and E. Mwambene, "Graphs, designs and codes related to the
n-cube," *Discrete Mathematics* 309 (2009), 3255-3269,
[doi:10.1016/j.disc.2008.09.024](https://doi.org/10.1016/j.disc.2008.09.024).
Theorem 1(a) and Result 2 state the dimension, self-duality and minimum
weight of the binary adjacency code of Q_d, crediting earlier work by
W. Fish and J. D. Key with P. Seneviratne. We use only the stated
minimum-distance theorem as an external premise for the stronger congruence;
our block identity and weaker congruences have independent arguments in
[PROOF.md](PROOF.md). The external proof has not been independently reviewed.

The author manuscript dated 2008-08-22 is available at
[the author's university site](https://cecas.clemson.edu/~keyj/Key/fikemwDMRR.pdf).
A 270,983-byte capture from the alternate author host
`https://www.math.clemson.edu/~keyj/Key/fikemwDMRR.pdf` has SHA-256
`825eedd30f23aa6f34307bbe33196aa1b5a5c37d62316812d93810cf615656d7`.
The local capture required disabling TLS certificate verification due to a
local issuer-chain failure, so this hash pins the observed bytes but does
not authenticate their origin. The university and publisher bibliographic
records and the same theorem text were also inspected via web retrieval.
No upstream Git commit was identified for this manuscript. Its license was not
established; no copy of the paper is redistributed in this package.
